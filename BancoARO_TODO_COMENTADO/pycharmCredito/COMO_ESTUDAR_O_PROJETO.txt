BANCO ARO - CÓDIGO COMENTADO EM LINGUAGEM SIMPLES

4. Para entender margin e padding, veja os CSS e os .txt correspondentes.

6. O arquivo BANCO.FDB é binário: não dá para comentar suas linhas como texto. Ele foi preservado sem modificação.
7. A ideia foi comentar SEM mudar a lógica das rotas ou o layout.
